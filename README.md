# Panadi Mohana Venkata Srinivas

I build practical software projects across full-stack web development, cloud operations, and recommendation systems. This portfolio focuses on clear architecture, reproducible setup, and honest reporting of what each project does and where it is still a demo.

## Selected projects

### [ApplyTrack](https://github.com/MohanaSrinivas/applytrack)

A full-stack job application tracker built with React, TypeScript, FastAPI, and PostgreSQL. Demonstrates JWT-based sign-in, user-scoped application records, backend and frontend tests, and Docker Compose local development.

[![CI](https://github.com/MohanaSrinivas/applytrack/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/MohanaSrinivas/applytrack/actions/workflows/ci.yml)

### [CloudOps Deployment Lab](https://github.com/MohanaSrinivas/cloudops-deployment-lab)

A local-first operations lab around the ApplyTrack workload. Demonstrates a Compose stack, GitHub Actions container publishing, Prometheus/Grafana configuration, and an optional Terraform EC2 example. The AWS example is separate and is not required to run the local stack.

[![Container build](https://github.com/MohanaSrinivas/cloudops-deployment-lab/actions/workflows/build-publish.yml/badge.svg?branch=main)](https://github.com/MohanaSrinivas/cloudops-deployment-lab/actions/workflows/build-publish.yml)

### [TasteMatch Recommender](https://github.com/MohanaSrinivas/tastematch-recommender)

A MovieLens-based recommendation baseline comparing genre TF-IDF content recommendations with item-item collaborative filtering. Includes a temporal holdout evaluation, ranking metrics, a FastAPI demo, and synthetic-data unit tests.

[![CI](https://github.com/MohanaSrinivas/tastematch-recommender/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/MohanaSrinivas/tastematch-recommender/actions/workflows/ci.yml)
